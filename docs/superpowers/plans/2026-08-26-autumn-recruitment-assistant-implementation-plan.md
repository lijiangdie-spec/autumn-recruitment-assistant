# 秋招助手开源化实施计划

## 原则

- 只在新仓库中实现；私人目录只读，发布桥接除外且默认关闭。
- 先复制明确白名单，再逐项净化；禁止从总目录做排除式打包。
- 每个阶段先补测试再改行为，阶段结束提交一次可运行状态。

## 1. 建立净化基线

1. 从现有 `autumn-recruitment` 复制源码、配置、测试与通用视觉资产；排除 `.env*`、`data/`、`.next/`、`node_modules/`、`artifacts/`、个人文档和缓存。
2. 从 `resume-writer` 只复制 `SKILL.md`、脚本、模板和合成示例；不复制 `data/`。
3. 重新生成 `.gitignore`、`.env.example`、0BSD、README 骨架与 npm 元数据。
4. 运行敏感信息扫描并移除姓名、绝对路径、私人 URL、金融偏好和个人文件名；提交净化基线。

## 2. 运行时配置与首次引导

1. 新增跨平台数据根解析、仓库内写入拒绝、原子 JSON 存储与 Zod Schema。
2. 建立 `profile.json`、`preferences.json`、素材和应用目录；数据库只保存岗位与投递索引。
3. 新增 `/api/setup`、`/api/profile`、`/api/preferences`、`/api/materials` 与环境体检接口。
4. UI 增加首启向导和设置工作区；未完成引导时不运行个性化评分。
5. 将硬编码城市、岗位族、届别、证书门槛、权重和阈值替换为用户配置驱动的通用规则。

## 3. 素材库三种入库方式

1. 实现项目/实习结构、草稿/确认状态、来源记录和 CRUD。
2. 访谈模式按 2–3 个问题一轮保存草稿；所有数字在确认前不可用于简历。
3. 旧简历上传仅接受 PDF/DOCX/TEX，限制体积并在应用内提取文本；原文件存于用户数据目录。
4. 仓库分析必须选择本地目录、解析真实路径并限制只读；收集 README、文件树和代码证据，不执行代码。
5. 为三种方式提供合成 fixture、API 测试与 UI 流程测试。

## 4. 双代理与简历流水线

1. 实现 `AgentAdapter`、任务 Schema、超时/取消、错误归一化和结构化日志。
2. Codex 使用 `exec --ephemeral --sandbox read-only --output-schema`；Claude 使用 `--print --json-schema --no-session-persistence` 且仅开放读取工具。
3. 将姓名、素材路径、基线简历、模板和文件名全部配置化；无照片和无基线均为正常状态。
4. 生成链路校验事实引用、单页、可提取文本、占位符、页尾和 PNG 预览；失败保留旧文件。
5. 通过 mock 分别覆盖 Codex、Claude、Schema 错误、超时、渲染失败和重试。

## 5. 岗位 feed 与网站

1. 定义版本化 feed Schema、白名单 DTO、稳定 ID、内容哈希、manifest 和客户端合并逻辑。
2. 新增远端 feed 同步接口与 UI 状态；同步只覆盖公开岗位字段，不触碰个人派生数据。
3. 生成静态岗位网站，提供搜索、筛选、来源、更新时间和版本状态。
4. 实现发布器：构建、校验、上传不可变 feed、切换 manifest、远端回读验证、失败 outbox/退避重试。
5. 在私人应用中最后加入默认关闭的发布桥接；未配置时零行为变化，并用数据库副本回归。

## 6. 跨平台、隐私与发布

1. 用 Node 体检/启动脚本覆盖 Windows 与 macOS；保留 Windows 快捷方式为可选功能。
2. 增加仓库与构建产物敏感扫描、pre-commit 检查、GitHub Actions 双系统矩阵和 Pages 工作流。
3. 完成 README、隐私说明、贡献指南、安全说明、迁移/备份和故障排查。
4. 运行 lint、单元/集成、build、E2E、视觉 QA、PDF/DOCX 全页校验和最终敏感扫描。
5. 用户创建空的公开 GitHub 仓库并提供 URL 后，推送 `main`、确认 CI、启用/验证 Pages，发布首个版本。

## 验收门槛

- 新仓库测试、lint、build 全绿；Windows 与 macOS CI 通过。
- 空白首启无需私人文件即可运行；Codex/Claude mock 均能生成同一契约的草稿。
- 公开 feed 的 DTO 测试证明个人字段不可能进入序列化结果。
- 全仓与构建产物敏感扫描零命中；Git 历史只包含净化后的文件。
- 原私人应用的启动、数据库、导入、投递、简历与文件夹回归不退化；发布桥接关闭时行为与基线一致。
